1

아닥사스다 왕은 포도주를 따르는 느헤미야의 얼굴을 보고 무엇이라고 물었나요? (느 2:2)

답: 네가 병이 없거늘 어찌하여 얼굴에 ( ) 이 있느냐 이는 필연 네 마음에 ( ) 이 있음이로다

2

왕이 "네가 무엇을 원하느냐"라고 물었을 때, 느헤미야가 대답하기 직전에 한 행동은 무엇인가요? (느 2:4)

답: 내가 곧 하늘의 하나님께 ( ) 하고

해설: 왕의 질문을 받은 절체절명의 순간, 느헤미야는 속으로 짧고 강렬하게 '총알 기도(묵도)'를 드렸어요. 이는 찰나의 순간에도 하나님의 지혜와 도우심을 구하는 역동적인 기도였어요. 평소에 넉 달 동안 기도로 준비했기에 위기의 순간 반사적으로 기도가 튀어나올 수 있었던 것이죠.

3

느헤미야는 왕에게 자신이 예루살렘으로 가서 성을 건축할 수 있게 해 달라고 요청하며, 구체적으로 두 가지 조서(편지)를 요구했습니다. 누구에게 내리는 조서였나요? (느 2:7-8)

답: 강 서쪽 ( ) 과 왕의 삼림 감독 ( )
정답 확인됨

해설: 느헤미야는 무작정 가겠다고 한 것이 아니라, 안전하게 통과할 수 있는 '통행증'과 건축에 필요한 목재를 얻을 '건축 자재 허가증'을 치밀하게 요구했어요. 이는 그가 단순히 기도만 한 것이 아니라, 무엇이 필요한지 행정적으로 완벽한 '마스터플랜'을 세워두고 준비했음을 보여줍니다.

4

페르시아의 거대한 왕이 이 모든 엄청난 요청을 허락한 진짜 이유는 무엇이라고 느헤미야는 고백했나요? (느 2:8)

답: 내 하나님의 선한 ( ) 이 나를 도우시므로
정답 확인됨

해설: 느헤미야는 자신이 말을 잘해서나 처세술이 뛰어나서 왕이 허락했다고 생각하지 않았어요. 하나님의 절대적인 은혜와 주권(하나님의 선한 손)이 왕의 마음을 움직이셨음을 온전히 고백했습니다.

5

[생각 나누기] 느헤미야는 위기의 찰나에 하나님께 '총알 기도(묵도)'를 드렸습니다. 나의 일상, 학교생활, 학원, 또는 친구 관계 속에서 1초 만에 마음속으로 급하게 하나님의 도우심을 구해야 하는 순간은 언제인가요? 그때 어떤 기도를 드릴지 적어 보세요.

STEP 02

2단계(화) - 관찰 해석 2: 영적 리더십과 신앙의 결단

목표: 현실을 냉철하게 파악하고 백성을 독려하며 대적의 훼방에 맞서는 신앙의 결단을 배웁니다.

1

예루살렘에 도착한 느헤미야가 3일 뒤 한밤중에 측근 몇 명만 데리고 은밀하게 한 일은 무엇인가요? (느 2:13-15)

답: 무너진 예루살렘 ( ) 과 불탄 성문을 살펴봄
정답 확인됨

해설: 느헤미야는 감정적으로 바로 일을 시작하지 않고, 밤에 비밀스럽게 폐허가 된 성벽의 상태를 직접 눈으로 꼼꼼히 조사했어요(현장 답사). 이는 영적인 사역을 감당할 때 현실의 문제를 정직하게 직시하고 철저하게 계획을 세우는 '인간의 책임'을 다하는 모습이에요.

2

느헤미야가 유다 백성들에게 하나님의 도우심과 왕의 허락을 전하며 "예루살렘 성을 건축하여 다시 수치를 당하지 말자"고 독려하자, 백성들은 어떻게 반응했나요? (느 2:18)

답: 일어나 ( ) 하고 모두 힘을 내어 이 선한 일을 하려 하매
정답 확인됨

해설: 백성들은 느헤미야를 통해 '하나님의 은혜'를 듣자, 오랜 패배주의를 딛고 스스로 용기를 내어(힘을 내어) 성벽 재건에 헌신하기로 결단했어요. 강요에 의해서가 아니라, 하나님의 은혜를 경험할 때 자발적으로 헌신이 터져 나오는 '복음의 패턴'을 보여주는 장면이에요.

3

유다 백성이 성벽을 건축한다는 소식을 듣고 산발랏, 도비야, 게셈은 어떤 적대적인 행동을 했나요? (느 2:19)

답: 우리를 ( ) 비웃어 이르되... 너희가 왕을 ( ) 하느냐
정답 확인됨

해설: 예루살렘이 회복되는 것을 가장 싫어한 사람들은 주변의 이방 총독들이었어요. 그들은 성벽 재건이 왕에 대한 반역이라며 정치적인 프레임을 씌워 조롱하고 협박했어요. 선한 일을 시작할 때 세상(사탄)은 반드시 방해하고 조롱한다는 영적 전쟁의 현실을 보여줍니다.

4

대적들의 비웃음에 맞서, 느헤미야는 그들에게 예루살렘에서 무엇이 없다고 단호하게 선언했나요? (느 2:20)

답: 아무 ( ) 도 없고 ( ) 도 없고 기억되는 바도 없다
정답 확인됨

해설: 느헤미야는 하늘의 하나님이 주시는 형통함을 선포하며, 대적들이 거룩한 성 예루살렘에 대해 어떠한 정치적, 법적, 종교적 권리도 없다고 완벽하게 선을 그었어요. 이는 타협과 혼합주의를 거부하고, 십자가 복음으로 세상과 구별되는 '교회의 거룩성(순결성)'을 지키려는 영적 독립 선언입니다.

5

[생각 나누기] 선한 일(예배, 전도, 헌신)을 하려고 할 때 주변에서 비웃거나 방해를 받은 적이 있나요? 산발랏과 도비야 같은 대적의 훼방에 흔들리지 않고 느헤미야처럼 단단한 마음을 가지려면 어떻게 해야 할지 나의 다짐을 적어 보세요.
